# 孕期高血压类型

孕期高血压主要分为三种类型：妊娠期高血压指妊娠20周后新发的高血压，多数无症状，产后12周多可恢复，但会增加未来高血压风险；慢性高血压指妊娠前或孕前已存在的高血压，部分人产前不知晓；子痫前期是妊娠20周后突发的高血压，常发生于妊娠晚期，常伴肝肾功能损伤及尿蛋白等症状，可能危及母婴生命。
