# 肺栓塞：突发肺动脉阻塞

肺栓塞（PE）是肺动脉突发阻塞，通常因血液凝块脱落并随血流进入肺部。这是一种严重疾病，可导致永久性肺损伤、血液低氧血症，以及因缺氧损害身体其他器官。
