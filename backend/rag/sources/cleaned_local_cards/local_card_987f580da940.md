# Anaphylaxis 可能影响多个器官

Anaphylaxis 可影响多个器官系统。皮肤表现为瘙痒、风团、发红和肿胀；鼻部出现打喷嚏、鼻塞或流涕；口腔有瘙痒、嘴唇或舌头肿胀；咽喉感到瘙痒、紧绷、吞咽困难及后部喉头肿胀；胸部出现呼吸困难、咳嗽、喘息、胸痛或紧绷感；心脏表现为脉搏微弱、晕厥或休克；胃肠道出现呕吐、腹泻或痉挛；神经系统则表现为头晕或晕厥。
