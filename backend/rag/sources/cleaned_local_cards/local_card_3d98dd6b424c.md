# 腹痛就医指南

若轻度腹痛持续一周以上，或伴有其他症状，请立即联系您的医疗保健提供者。若出现以下紧急情况，需立即寻求医疗帮助：腹痛突然且剧烈；同时伴有胸痛、颈部或肩部疼痛；呕吐鲜血或粪便带血；腹部僵硬、坚硬且触痛明显；无法排便，尤其是伴有呕吐时。
