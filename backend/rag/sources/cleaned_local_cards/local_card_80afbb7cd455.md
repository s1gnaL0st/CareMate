# 扁桃体炎检查流程

儿童确诊扁桃体炎后，医生通常会安排咽拭子或快速链球菌检测。快速检测在办公室进行，结果几分钟内即可出；而咽拭子培养需在实验室完成，通常需要数天。咽拭子培养更准确可靠。若快速检测呈阴性，医生仍可能进行咽拭子培养，以确保排除链球菌感染。
