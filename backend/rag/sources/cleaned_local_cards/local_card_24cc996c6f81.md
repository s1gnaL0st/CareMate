# 感冒常见病毒

超过200种病毒可引发感冒，但鼻病毒最为常见。感冒病毒传染性极强，可通过空气和密切接触传播。接触被病毒污染的物体后触摸眼、口或鼻也可能感染。例如，与感冒患者握手或触摸带有病毒的门把手后触摸面部，均可能导致感冒。
