# 药物相互作用定义

药物相互作用指与特定药物、食物或补充剂合用时，或伴随特定医疗状况时，药物在体内作用方式发生改变的现象。常见例子包括：两种药物如阿司匹林与抗凝药；药物与食物如他汀类与西柚；药物与补充剂如银杏与抗凝药；以及药物与医疗状况如阿司匹林与胃溃疡。
