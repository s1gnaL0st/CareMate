# 突发心脏骤停

突发心脏骤停（SCA）通常无预警发生，需紧急救治。医护人员极少通过医疗测试诊断此情况，因为发作时无法进行。通常是在事件发生后，通过排除导致患者突然昏厥的其他原因来确诊。
