# 牙齿蛀牙检查要点

牙医通常通过观察牙齿和用牙科工具探查来发现蛀牙和龋洞。牙医还会询问您是否有相关症状。在某些情况下，可能需要拍摄牙科 X 光片。

标签：dental, Tooth Decay, Key information, 牙齿蛀牙, 牙医检查, 牙科 X 光片, 症状询问

疾病类别：Tooth Decay
