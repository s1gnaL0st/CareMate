# 糖尿病治疗概述

糖尿病治疗旨在管理血糖水平。1型糖尿病患者需每日注射或植入胰岛素泵，部分还需联合使用其他药物。2型糖尿病患者可通过健康饮食、控制体重及规律运动改善甚至逆转病情，部分患者仍需服用药物。妊娠期糖尿病通过健康饮食和运动可暂时降低血糖，但产后风险较高，未来患2型糖尿病概率增加。所有治疗方案均须与医生沟通。
