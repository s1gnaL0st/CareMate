# 突发心脏骤停急救指南

大多数警察、急救技师及其他急救人员均受过培训并配备除颤器。若有人出现心脏骤停（SCA）的征兆或症状，请立即拨打 9-1-1。越早联系急救，越能迅速启动救命治疗。
