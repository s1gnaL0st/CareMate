# COPD 急救指南

患有 COPD 的患者应知晓何时及何处获取帮助。若出现严重症状，如呼吸困难或无法说话，需立即寻求紧急医疗救助。若症状加重或出现感染迹象（如发热），应及时联系您的医疗保健提供者。
