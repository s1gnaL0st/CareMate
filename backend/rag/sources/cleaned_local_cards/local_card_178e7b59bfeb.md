# 普通感冒无治愈方法

普通感冒无法治愈，但可通过休息、补水、使用加湿器、盐水漱口、生理盐水滴鼻或喷雾、以及服用非处方止痛药或感冒咳嗽药来缓解症状。然而，使用某些药物时需格外谨慎。
