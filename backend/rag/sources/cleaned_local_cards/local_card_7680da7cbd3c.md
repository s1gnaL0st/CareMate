# 偏头痛关键信息

偏头痛是一种反复发作的头痛类型，表现为搏动性或搏动性中度至剧烈疼痛。疼痛常位于头部一侧，并可能伴随恶心、虚弱等其它症状。患者可能对光和声音感到敏感。
