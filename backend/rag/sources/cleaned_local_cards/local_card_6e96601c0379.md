# 如何识别脓毒症

您的医疗保健提供者将询问您的病史，包括症状；进行体格检查，包括检查生命体征（如体温、血压、心率和呼吸）；可能会开具实验室检查，以检测感染或器官损伤的迹象；可能会安排影像学检查，如 X 光或 CT 扫描，以确定感染的位置。
