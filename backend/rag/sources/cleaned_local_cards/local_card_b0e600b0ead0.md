# 视力障碍与失明关键信息

衰老本身不会导致视力丧失，但许多老年人更常见的疾病可引发此问题。美国低视力与失明的主要诱因是年龄相关的眼部疾病，如黄斑变性、白内障和青光眼。此外，其他眼部疾病、眼部受伤及出生缺陷也可能导致视力受损。
