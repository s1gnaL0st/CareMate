# 抗凝药物与溶栓治疗

抗凝药如阿司匹林等，用于防止血栓扩大或新血栓形成，可能引发出血。溶栓药用于溶解大血栓，若患者出现严重症状或并发症，医生可能建议使用。此类药物可能导致突发大出血，仅在危及生命的情况下使用。
