# 眼部感染概述

眼睛可能因细菌、真菌或病毒而感染。眼部感染可发生于眼部的不同部位，可能仅影响一只眼或双眼。两种常见眼部感染是：结膜炎，俗称“红眼病”，通常由感染引起，儿童易患且传染性极强；睑腺炎，即眼睑上的小肿块，常因皮肤细菌进入睫毛毛囊所致。
