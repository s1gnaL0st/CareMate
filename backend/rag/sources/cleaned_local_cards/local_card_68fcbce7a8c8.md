# 孕期健康问题的定义

孕期健康问题是指可能影响孕妇或胎儿健康的疾病或状况。某些问题会增加发展为高危妊娠的风险。高危妊娠是指孕妇、胎儿或两者均面临比典型妊娠更高的健康风险状况。
