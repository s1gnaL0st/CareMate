# 癫痫发作关键信息

癫痫发作通常持续30秒至2分钟，不会造成永久性伤害。但若发作持续超过5分钟，或患者连续发作且未清醒，则属医疗急症。癫痫发作可能由多种原因引起，包括药物、高热、头部外伤及特定疾病。反复因脑部疾病发作的患者被诊断为癫痫。
