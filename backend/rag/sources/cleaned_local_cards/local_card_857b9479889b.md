# 心律失常筛查指南

为检测心律失常，医生可能安排心电图（EKG）检查，该测试记录心脏电活动，是发现心律失常最常见的方法。此外，医生还可能询问您的病史、症状及生活习惯；进行体格检查，包括听诊心跳和脉搏；开具血液及其他心脏检查；检查双腿或脚部是否有肿胀；并寻找甲状腺疾病等可能导致心律失常的其他健康条件。
