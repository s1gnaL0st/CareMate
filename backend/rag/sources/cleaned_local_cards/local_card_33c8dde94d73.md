# 胸痛可能并非心梗

胸痛虽令人担忧，但并非总是意味着心脏病发作。它可能由多种原因引起，包括心脏问题如心绞痛、情绪波动引发的恐慌发作、消化系统问题如胃食管反流或食管疾病、肌肉酸痛、肺部疾病如肺炎、胸膜炎或肺栓塞，以及胸壁炎症如胸骨膜炎。
