# 脓毒症症状

脓毒症可能引发多种症状，包括呼吸急促和心跳加快、呼吸困难、意识混乱或定向力障碍、剧烈疼痛或不适、发热或寒战、以及皮肤潮湿或出汗。

标签：sepsis, Sepsis, Sepsis can cause one or more of these symptoms:, 脓毒症, 症状, 急救

疾病类别：Sepsis
