# 癫痫症状简介

癫痫是脑部问题的表现，源于大脑突发的异常电活动。人们常将癫痫与全身剧烈抽搐相联系，但并非所有癫痫都会导致此类症状。癫痫有多种类型，部分症状轻微。癫痫主要分为两类：局灶性发作（部分性发作）仅发生于大脑某一区域；全身性发作则源于大脑双侧异常活动。
