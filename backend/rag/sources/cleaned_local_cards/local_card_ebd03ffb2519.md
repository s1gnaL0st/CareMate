# 抑郁症关键信息

抑郁症不仅是几天内感到悲伤或易怒的感觉，而是一种严重的精神疾病。作为美国最常见的精神疾病之一，它会影响您的思维、感受及日常生活。您可能无法理解为何如此，但基本的日常活动如睡眠、进食或工作可能变得困难。抑郁症通常需要长期治疗，但尽早寻求帮助有助于管理症状。
