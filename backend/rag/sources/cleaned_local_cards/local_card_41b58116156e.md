# 病毒引起肺炎

呼吸道病毒可能引发肺炎。病毒性肺炎通常较轻，数周内自行痊愈。但有时病情严重，需住院治疗。患病毒性肺炎者易并发细菌性肺炎。常见病毒包括呼吸道合胞病毒（RSV）、普通感冒和流感病毒，以及新冠病毒（SARS-CoV-2）。
