# 国家糖尿病、消化与肾脏疾病研究所

NIH 是负责糖尿病、消化系统和肾脏疾病研究的美国国立卫生研究院。该机构致力于通过科学发现改善患者健康，特别是在慢性肾病管理领域。其研究涵盖从早期诊断到治疗方案的全面评估，为临床实践提供关键依据。
