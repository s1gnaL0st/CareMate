# 视力障碍与失明

视力障碍指视力丧失，包括完全失明或大部分视力丧失。低视力指仍有部分视力，但影响日常活动，如阅读、购物、烹饪等。低视力无法通过眼镜、隐形眼镜、药物或手术治愈。
