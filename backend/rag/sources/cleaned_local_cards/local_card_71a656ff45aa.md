# 自杀：重大公共卫生问题

自杀是美国主要的公共卫生问题，也是美国死亡的主要原因之一。自杀和自杀尝试均可能产生长期危害：幸存者可能遭受严重伤害，影响长期健康，并伴有抑郁或其他心理健康问题。自杀身亡会对家庭、朋友和社区造成冲击，引发悲伤、震惊、愤怒和自责。部分人可能发展为创伤后应激障碍（PTSD）、抑郁或焦虑，并面临再次自杀的风险。
