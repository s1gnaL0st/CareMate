# 突发心脏骤停

突发心脏骤停（SCA）是指心脏突然停止跳动，导致血液无法流向大脑和其他重要器官。若不及时处理，通常会在数分钟内致死。但通过心肺复苏（CPR）和除颤器的快速干预，可能挽救生命。
