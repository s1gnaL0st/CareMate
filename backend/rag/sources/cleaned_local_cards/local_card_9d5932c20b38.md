# 糖尿病症状因类型而异

1型糖尿病症状通常迅速出现且严重。2型糖尿病症状往往缓慢发展，可能持续数年。症状可能轻微到难以察觉。妊娠期糖尿病通常无明显症状，若有则可能较轻。孕妇通常在怀孕24至28周期间接受筛查。
