# 国立卫生研究院简介

NIH 是负责糖尿病、消化系统和肾脏疾病研究的美国国家机构。该机构致力于通过科学发现推动医学进步，改善患者健康。其核心工作包括支持基础医学研究、临床转化项目以及公共卫生政策制定。
