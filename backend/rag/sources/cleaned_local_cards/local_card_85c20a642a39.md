# 贫血基础知识

贫血是指血液携氧能力不足。最常见的原因是缺铁，因为身体需要铁来制造血红蛋白。血红蛋白是一种富含铁的红蛋白，赋予血液红色，负责将氧气从肺部输送至全身。

标签：anemia, Anemia, Key information, 贫血, 缺铁, 血红蛋白, 氧气输送

疾病类别：Anemia
