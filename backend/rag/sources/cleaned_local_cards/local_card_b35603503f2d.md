# 自杀预警与求助指南

若发现有人或他人有自杀风险，请立即寻求专业帮助，特别是行为发生明显变化时。若遇紧急情况，请直接拨打 120。若非紧急，可采取以下五个步骤：询问其是否自杀；确保其人身安全；确认是否有自杀计划并移除危险物品；陪伴其度过难关；协助其联系专业资源。
