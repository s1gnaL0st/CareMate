# 骨折分类

骨折可按是否破皮分为闭合或开放性骨折；按断裂方向或形态可分为线性或模式性骨折；按成因可分为应力性骨折；按骨折部位可包括面部骨折等。

标签：injury, Fractures, There are different ways to describe fractures . For example, there are different types of fractures based on:, 骨折, 分类, 闭合性, 开放性, 应力性, 面部骨折

疾病类别：Fractures
