# 缺血性卒中急性治疗

缺血性卒中的急性治疗通常使用药物。患者可能获得溶栓药物，如组织型纤溶酶原激活剂（tPA），用于溶解血栓。该药物必须在症状开始后的4小时内使用，越早使用恢复机会越大。若无法获得溶栓药，可考虑抗血小板聚集药物或抗凝药物以阻止或控制血栓形成。此外，若存在颈动脉动脉粥样硬化，可能需要手术疏通堵塞的颈动脉。
