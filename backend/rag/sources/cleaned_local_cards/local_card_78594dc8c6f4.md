# 癌症症状因类型而异

癌症症状取决于癌症类型。例如，可能出现的症状包括：乳房肿块；尿液或粪便中带血；不明原因的出血或瘀伤；不愈合的伤口；吞咽困难；新出现的痣或原有痣的变化。
