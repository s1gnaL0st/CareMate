# 疲劳症状说明

疲劳表现为身体或精神上的疲惫感，可能影响日常生活。它可能是运动、压力或睡眠不足的正常反应，但也可能是疾病信号。若持续数周感到疲倦，请及时联系医生，以便查明原因并提供缓解建议。
