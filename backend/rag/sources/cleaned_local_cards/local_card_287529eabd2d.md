# 肾脏衰竭关键信息

健康肾脏通过清除多余液体、矿物质和废物来净化血液，并产生维持骨骼强健和血液健康的激素。然而，若肾脏受损，其功能便会失常，导致有害废物在体内堆积，血压可能升高，身体可能滞留多余水分且无法产生足够的红细胞。这种情况被称为肾脏衰竭。
