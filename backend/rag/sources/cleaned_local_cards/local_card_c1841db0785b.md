# 癌症诊断说明

目前尚无单一测试可确诊癌症，诊断通常依据您的症状。医生可能会询问您的病史、家族健康状况，并进行身体检查或筛查（如乳腺钼靶、结肠镜或宫颈细胞学检查），必要时还会开具血液或影像学检查。
