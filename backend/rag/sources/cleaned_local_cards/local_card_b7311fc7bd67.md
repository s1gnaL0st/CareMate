# 发热治疗原则

治疗需根据发热原因而定。若体温过高，医疗保健提供者可能建议服用对乙酰氨基酚或布洛芬等非处方药。成人也可服用阿司匹林，但儿童发热时严禁服用阿司匹林。同时，应保证充足饮水，以防脱水。
