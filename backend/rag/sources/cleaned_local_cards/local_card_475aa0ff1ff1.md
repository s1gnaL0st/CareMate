# 过敏症关键信息

过敏症可引发流涕、打喷嚏、瘙痒、皮疹、肿胀或哮喘等多种症状，严重程度不一。过敏性休克是一种危及生命的严重反应。医生通过皮肤和血液测试进行诊断。治疗方法包括药物、脱敏注射及避免致敏物质。
