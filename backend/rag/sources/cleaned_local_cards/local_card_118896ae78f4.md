# 自杀预警信号

自杀预警信号包括谈论自杀或自杀念头、制定计划或寻找方法、购买枪支或囤积药物、感到空虚绝望、极度痛苦、感到自己是他人负担、滥用酒精或药物、情绪焦虑或行为鲁莽、睡眠障碍、社交退缩、易怒或寻求报复、情绪剧烈波动以及向亲友告别或整理事务。
