# 哮喘简介

哮喘是一种慢性肺部疾病，影响气管，即进出肺部的空气通道。当哮喘发作时，气道会发炎并变窄，导致喘息、咳嗽和胸部紧绷感。当症状比平时加重时，称为哮喘发作或加重。
