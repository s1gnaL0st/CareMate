# ME/CFS 疲劳特征

ME/CFS 的极度疲劳不同于休息后缓解的普通疲劳。该病症的疲劳持续时间较长，休息后不会好转，并限制日常活动能力。

标签：undifferentiated, Fatigue, Key information, ME/CFS, 疲劳, 休息无效

疾病类别：Fatigue
