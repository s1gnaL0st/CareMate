# 感冒常见症状与警示

感冒后多数人在一周至两周内会好转。但部分人可能并发支气管炎或肺炎，多见于免疫力低下、哮喘或呼吸道疾病患者。若出现呼吸困难、脱水、持续超过4天的发热、超过10天无改善的症状，或发热咳嗽好转后反复/加重，或慢性病情恶化，请立即联系医生。
