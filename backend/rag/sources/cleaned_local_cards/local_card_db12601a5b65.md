# 医院检查项目

住院或有严重症状、高龄或合并症者可能需进一步检查。包括痰液检查，检测肺部深部分泌物中的细菌；胸部 CT 扫描，评估肺部受累程度，并可能发现肺脓肿或胸腔积液等并发症。此外还包括胸腔积液培养、血氧饱和度检测，以及支气管镜检查，以深入观察肺部气道情况。
