# 药物不良反应

药物不良反应是指药物引起的非预期、通常不愉快的副作用。大多数副作用轻微，如胃部不适、口干或嗜睡，停药后可自行消失。部分副作用更为严重。有时药物会与患者已有的疾病相互作用，引发不良反应。例如，患有心脏病的人服用某些去充血剂可能导致心跳过快。
