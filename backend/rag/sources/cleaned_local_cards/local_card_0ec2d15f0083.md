# 突发心脏骤停急救指南

突发心脏骤停是紧急情况，患者需立即使用除颤器进行抢救。除颤器通过电击恢复心脏正常节律。除颤需在骤停后数分钟内完成，此时应立即开始心肺复苏并持续进行，直至除颤器可用。心肺复苏有助于维持大脑及其他器官的血液供应，直到心脏恢复正常节律。
