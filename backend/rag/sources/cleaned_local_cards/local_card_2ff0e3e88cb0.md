# 癌症并非单一疾病

癌症并非一种疾病，而是多种疾病。癌症起源于身体细胞，这些细胞是身体的基本构建单元。通常，身体会根据需要形成新细胞，替换死亡的旧细胞。有时，这一过程会出现错误。新细胞在不需要时也会过度生长，而旧细胞在应该死亡时却未能凋亡。这些多余的细胞可以形成一种称为肿瘤的肿块。
