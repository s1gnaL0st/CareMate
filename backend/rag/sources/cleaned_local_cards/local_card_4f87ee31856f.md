# 肿瘤分类与转移

肿瘤分为良性与恶性。良性肿瘤不会癌变，而恶性肿瘤会。恶性细胞可侵入邻近组织，并脱落至身体其他部位。癌症从一处转移到另一处的过程称为转移。症状及治疗方案取决于癌症类型及其进展程度。
