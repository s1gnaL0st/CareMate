# 心梗症状

心梗患者可能伴有恶心、呕吐、头晕、心悸（心跳加速或沉重）及眼前发黑等症状。部分患者会出现冷汗。值得注意的是，女性常表现出与男性不同的症状，例如无缘无故感到疲劳。
