# 心律失常症状

心律失常可能无明显症状，但医生在常规体检中可能发现。常见症状包括心跳过快或过慢、心跳节律不齐如漏跳或乱跳、胸痛或不适、头晕或晕厥、呼吸困难、出汗以及疲劳或虚弱。
