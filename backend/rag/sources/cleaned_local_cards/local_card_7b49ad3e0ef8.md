# 美国国立卫生研究院

NIH 是负责心脏、肺部和血液研究的美国联邦机构。该机构致力于通过基础研究和临床转化推动医学进步，特别是在贫血等血液疾病领域。其研究涵盖红细胞生成、铁代谢及血液疾病治疗等多个方向，为公众提供权威的健康信息支持。
