# 头痛急救提示

并非所有头痛都需要医生处理，但某些头痛可能预示更严重的疾病。若出现突发性剧烈头痛，请立即告知您的医疗保健提供者。若头痛伴随头部外伤史、颈部僵硬、发热、意识丧失或眼部/耳部疼痛，需立即寻求医疗帮助。
