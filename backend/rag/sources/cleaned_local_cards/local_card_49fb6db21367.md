# 扁桃体炎治疗指南

扁桃体炎的治疗取决于病因。若为病毒感染，目前尚无特效药物可治愈。若为细菌感染（如链球菌性扁桃体炎），儿童需服用抗生素。关键在于必须完整服用抗生素，即使症状消失，以防细菌残留导致复发。
