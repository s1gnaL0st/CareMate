# 心肌梗死治疗与康复

治疗可能包括抗凝药物以溶解和预防血栓、氧气疗法以及冠状动脉旁路移植术或经皮冠状动脉介入术（PCI）。心肌梗死后，心脏康复和生活方式改变有助于恢复。
